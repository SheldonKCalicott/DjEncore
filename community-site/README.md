# DJ Encore Community Site

This folder contains the public-facing Vercel-ready landing page for the DJ Encore community.

## Deploy on Vercel

1. Import this repository into Vercel.
2. Set the project root to the `community-site` folder.
3. Use the default static configuration.
4. Deploy.

The site is static and does not require a Node server.

## Files

- `index.html` — landing page
- `styles.css` — styling
- `app.js` — list rendering and filtering
- `artists.json` — public artist list

## Notes

This is intentionally privacy-safe. It only stores artist names and optional tags so users can browse and discover community-driven requests.
